# Board Module (Совет директоров)

Модуль для подготовки и проведения заседаний совета директоров с голосованием
на планшетах внутри защищённого контура компании.

## Overview

Серверная часть модуля «Совет директоров» продукта Effective Office.
Позволяет секретарю создать заседание, настроить вопросы и правила голосования,
подключить планшеты участников, провести последовательное голосование и получить
агрегированные итоги для протокола. Индивидуальные ответы участников удаляются
после завершения заседания — данные хранятся только в памяти сервера.

**Key capabilities:**

- Создание и подготовка заседания (название, дата, участники)
- Вопросы повестки: «за/против/воздержался» и «выбор одного варианта»
- Настройка кворума и правила принятия решения для каждого вопроса
- Подключение и назначение планшетов участникам
- Проведение голосования с агрегированным итогом (без раскрытия голосов)
- Автоматическое удаление рабочих данных после завершения заседания

## Architecture

Модуль повторяет слоистую архитектуру остальных фич (см. `feature/sport`):

```
board/
└── core/                                     # Основной модуль
    ├── controller/
    │   └── BoardController.kt                # REST endpoints
    ├── service/
    │   └── BoardService.kt                   # Бизнес-логика, хранение в памяти
    ├── domain/
    │   └── model/
    │       ├── Meeting.kt                    # Заседание
    │       ├── Question.kt                   # Вопрос и правила голосования
    │       └── Vote.kt                       # Голос участника
    ├── dto/
    │   ├── MeetingDTO.kt                     # DTO заседания
    │   └── BoardDtoMapper.kt                 # Конвертация модель -> DTO
    └── exception/
        ├── BoardExceptions.kt                # Исключения модуля
        ├── BoardErrorCodes.kt                # Коды ошибок
        └── BoardExceptionHandler.kt          # Глобальный обработчик ошибок
```

Отличие от sport: провайдеры не нужны — данные живут в памяти сервера и
удаляются после завершения заседания (требование безопасности из паспорта
проекта).
